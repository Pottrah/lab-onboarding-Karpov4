# Отчет по практическому занятию №7. Анализ потоков данных, дизассемблирование и линтинг

## 1. Анализ потоков данных (DFA)

### 1.1. Таблица Def-Use цепочек

| Переменная | Def (определение) | Use (использование) |
|---|---|---|
| `log_entry` | Первоначальное присваивание `"Start processing"`; формирование итогового сообщения | Использование при записи в файл |
| `status` | Присваивание `"approved"` внутри условия `amount > 0` | Формирование сообщения и возврат из функции |
| `balance` | Получение результата `get_balance(user_id)` | Вычисление `new_balance` |
| `new_balance` | Вычисление `balance - amount` | Передача в `update_balance()` |
| `file` | Открытие файла `audit_log.txt` | Запись сообщения в файл |

### 1.2. Описание выявленных дефектов

- **Дефект 1 (Неинициализированная переменная):** если `amount <= 0`, переменной `status` не присваивается значение. При обращении к ней возникает `UnboundLocalError`.
- **Дефект 2 (Мертвое присваивание):** первоначальное значение `log_entry = "Start processing"` перезаписывается до использования, поэтому первое присваивание не влияет на результат.
- **Дефект 3 (Утечка ресурса):** файл открывается без гарантированного закрытия. Для исправления необходимо использовать конструкцию `with open(...)`.

## 2. Дизассемблирование

### 2.1. Восстановленный код на Python

```python
def calculate_sum():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```

### 2.2. Краткое пояснение логики работы ассемблерного фрагмента

Ассемблерный код суммирует целые числа от 1 до 10 включительно. Результат вычисления — 55.
