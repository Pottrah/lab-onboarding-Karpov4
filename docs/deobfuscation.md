Деобфускация кода

Расшифрованная строка:
import os; os.system('rm -rf /')

Анализ угрозы:
Команда rm -rf / пытается рекурсивно удалить файлы и каталоги начиная с корневого каталога системы. При успешном выполнении это может привести к уничтожению данных и нарушению работы операционной системы.

Методы защиты:
1. Не выполнять неизвестный код через exec().
2. Проверять и анализировать код перед запуском.
3. Использовать статический анализ.
4. Запускать подозрительные программы в изолированной среде.****
