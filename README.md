## Практическая работа 8. Часть 2: Аудит системы

### Обоснование выбора ПО
* **Базовый набор:** Офисный пакет (LibreOffice/МойОфис) необходим для работы с текстами и таблицами. Архиватор (7-Zip) — для распаковки почтовых архивов. Программы PDF (Foxit/Sumatra) — для чтения инструкций и договоров.
* **Излишнее ПО:** Проверяются игры (Steam) для контроля рабочего времени, торренты (uTorrent) для снижения рисков вирусов и нагрузки на сеть, мессенджеры (Telegram, Discord) для проверки их согласованности с ИТ-политикой.

### Тестирование логики
1. **Тест черного списка:** В файл `apps_list.txt` была искусственно добавлена строка `qBittorrent`. Скрипт успешно отловил ее в блоке анализа торрентов и выдал рекомендацию.
2. **Тест белого списка:** Был временно переименован критерий поиска архиватора `7-Zip` на несуществующий. Скрипт зафиксировал отсутствие архиватора и вывел правильное предупреждение с рекомендацией к установке.

### Ограничения решения
* Поиск завязан на текстовые имена в реестре `Uninstall`. Если программа установлена портативно (Portable) без записи в реестр, скрипт её не увидит.
